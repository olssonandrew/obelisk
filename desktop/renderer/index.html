Web pages

    How saved pages work

    Each page becomes one WACZ file on the Reference shelf, under Saved websites. WACZ is the open web-archive format used by libraries: inside is a WARC holding every response the page received, so other tools such as ReplayWeb.page can open it without Obelisk.

    The Wayback Machine option fetches the Internet Archive’s original recording of a page, which is useful when the page has changed or gone. Nobody can list in advance exactly which days a page was recorded, so “copies over time” asks for the recording nearest each point in the span and drops repeats; you choose which to keep before anything is saved. Requests are paced, because the Archive is a shared, donated service.

    Pages behind a login, endless feeds and streaming video are not captured. Each address is saved as one page, not a whole site. What you save is for your own reference: the rights to a page stay with whoever published it.

    Software & AI

    An archive is only useful if you can still open it. Keep the readers and tools it depends on alongside the files. Saved packages appear on the Software shelf.

    Running an AI model offline

    Run a model

    1. Save a compatible installer

      Download the version for your computer. Add it here to keep a copy.

    2. Install the application

      Reveal the installer and run it using your operating system.

    3. Load your model

      For LM Studio, use a supported GGUF model. Use lms import <path-to-model.gguf> after installing LM Studio’s command-line tool.

    4. Test before going offline

      Load the model and send a message. Runtime downloads and memory requirements vary by model.

    Models and installers stay as separate files in this archive. Obelisk does not run models or install software.
