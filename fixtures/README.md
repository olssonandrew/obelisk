# Demo fixtures

`welcome.txt`, `field-notes.md`, `coast.svg`, and `dunes.svg` are original demo
material created for this project. The seed script also synthesizes a six-second
WAV tone. These materials are dedicated to the public domain under **CC0-1.0**:
https://creativecommons.org/publicdomain/zero/1.0/

The remaining demo entries are descriptive placeholders. No Wikipedia snapshot,
map dataset, third-party software, archived website, or model weights are bundled.

`motion-study.mp4` is an original four-second geometric animation generated with FFmpeg, also CC0-1.0. FFmpeg is not required to run Obelisk.
